资金正确性（一）：账本
调用方报事实，账本定科目
Accounting Event账务核心订阅（MQ）
或支付核心 RPC 触发
Posting Rule账本按商户配置
决定科目与借贷方向
会计分录（Posting）一次事件展开多组平衡分录
每组借贷必须平衡
场景：用户支付 100 元　·　支付宝费率 0.6%　·　商户费率 0.8%　·　一次 capture 事件 = 三组平衡分录
资金事实 毛额 100
借CHANNEL_RECEIVABLE : 支付宝+100.00
贷MERCHANT_PAYABLE : M001+100.00
商户手续费 平台收入 0.80
借MERCHANT_PAYABLE : M0010.80
贷FEE_REVENUE : PLATFORM0.80
渠道手续费 平台成本 0.60
借CHANNEL_FEE_EXPENSE : 支付宝0.60
贷CHANNEL_RECEIVABLE : 支付宝0.60
平台利润 = 收入 0.80 − 成本 0.60 = 0.20（损益轧差，非独立科目）
两级科目
一级：科目定义 Definition
（资产 / 负债 / 收入 / 费用）
二级：科目实例 Instance
（按商户 / 渠道分户）
分录汇总 · 净额口径 商户应付净额 = 100 − 0.80 = 99.20
渠道应收净额 = 100 − 0.60 = 99.40
三组各自借贷平衡 · 按期间勾稽
领域边界：调用方不需关心借贷科目，只需上报账务事件
账本职责：科目与借贷方向由账本内部决定
复式记账 · 借贷必须平衡 · 金额一律整数分
